استبيان طلاب مهارات الاتصال والتواصل
=====================================
النشر على GitHub Pages:
1) أنشئ مستودعاً جديداً (مثلاً comm-skills-survey) وارفع كل الملفات في هذا المجلد إلى جذره.
2) Settings > Pages > Deploy from a branch > main > /(root).
3) رابط الطلاب:  https://<حسابك>.github.io/comm-skills-survey/
   رابط لوحة المحاضر: .../admin.html   (كلمة المرور الأولية: CPJFErZNMkny — غيّرها من اللوحة)
